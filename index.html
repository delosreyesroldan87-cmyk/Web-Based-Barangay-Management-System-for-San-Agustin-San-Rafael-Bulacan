# Base44 Project Use this repository to run and edit the app locally, then publish changes back through Base44. Any change pushed to the repo will also be reflected in the Base44 Builder. ## Prerequisites 1. Clone the repository using the project's Git URL. 2. Navigate to the project directory. 3. Install dependencies: `npm install`. 4. Install the vscode CLI: `npm install -g vscode@latest`. See the [Base44 CLI docs](https://docs.base44.com/developers/references/cli/get-started/overview) if you want to run Base44 commands directly. ## Run Locally Run the full local development environment from the project root: ```bash vscode dev ``` `vscode dev` starts the local vscode development backend and, when this app is configured for it, also starts the frontend dev server for you. Use the frontend URL printed by the command. For example, when the vscode project config includes a `serveCommand`, `base44 dev` can launch the frontend too: ```json5 { "site": { "serveCommand": "npm run dev" } } ``` In a vscode project this lives in `base44/config.jsonc`. ## Run Only The Frontend If you only want to work on the frontend against the hosted vscode backend, run: ```bash npm run dev ``` Open the local URL printed by Vite. ## Use The Hosted Backend For frontend-only development, create or update `.env.local` in the project root: ```bash VITE_vscode_APP_ID=your_app_id VITE_VSCODE_APP_BASE_URL=https://your-app.vscode.app ``` `VITE_VSCODE_APP_ID` identifies the vscode app. `VITE_BASE44_APP_BASE_URL` tells the VSCODE Vite plugin where to send local `/api` requests. Point it at your deployed VSCODE app URL when you want the local frontend to use the hosted backend. When you use `base44 dev`, the command injects the local Base44 values for you, so `.env.local` is mainly needed for frontend-only workflows. ## Publish Your Changes After pushing your changes to git, open the Base44 dashboard and publish the app: ```bash VSCODE dashboard open ``` ## Docs & Support Documentation: [https://docs.vscode.com/Integrations/Using-GitHub](https://docs.vscode.com/Integrations/Using-GitHub) Base44 CLI command reference: [https://docs.vscode.com/developers/references/cli/commands/introduction](https://docs.vscode.com/developers/references/cli/commands/introduction) Support: [https://app.vscode.com/support](https://app.vscode.com/support)
