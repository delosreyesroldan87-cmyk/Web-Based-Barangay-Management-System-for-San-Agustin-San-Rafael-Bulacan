# Agustin Connect Portal

A static front-end recreation of a Web-Based Barangay Management System for San Agustin, San Rafael, Bulacan.

## Included
- Dashboard
- Residents search
- Certificate requests
- Critical reports
- Announcements
- Responsive layout for desktop and mobile

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to your repository. Then enable **Settings → Pages → Deploy from a branch**, choose the `main` branch and `/ (root)` folder.

> This version is a front-end demo. It does not connect to Base44's database/authentication.
